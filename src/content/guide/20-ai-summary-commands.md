# 摘要与自定义命令

## 文档摘要

拿到一篇长文档，先看几句话的摘要和要点，再决定细读哪里。

**在哪里**：侧栏的「大纲」页（只打开一个文件时是「目录」）最上面的「✦ 摘要」卡片；也可以 <kbd>Ctrl+J</kbd> →「生成摘要」。阅读和编辑时都能用。

<a class="shot" href="../images/ai-summary.webp" target="_blank"><img src="../images/ai-summary.webp" alt="摘要卡片" loading="lazy" decoding="async"></a>

- 第一次点「生成摘要」，AI 读全文，写 3 到 5 句话的概括和几条要点
- 「复制」把摘要复制下来；「重新生成」再写一份
- 卡片底部写着是哪个模型、什么时候生成的
- 文档改过以后，卡片上提示「文档改过了，摘要可能过时」，点「重新生成」才会重写，不会自己去请求
- 很长的文档会按章节分段总结，再合在一起

摘要**不写进文档**，存在 Marlin 自己的数据文件夹里。下次打开这篇文档直接显示，不用再请求；在 Marlin 的文件树里改名、移动文档，摘要跟着走。

## 自定义命令

内置命令不完全合你的心意，或者有自己常用的要求（「按周报格式整理」「译成日文」），可以写成自己的命令，和内置命令一样出现在 <kbd>Ctrl+J</kbd> 的面板里。

**一个 Markdown 文件就是一条命令**：文件名是命令的名字，放在命令文件夹里；文件夹里的子文件夹就是面板里的分组。

**命令文件夹在哪**：设置 →「AI」→「打开命令文件夹」。安装版是 `%APPDATA%\dev.marlin-md.marlin\ai-commands`，便携版是程序旁边的 `data\ai-commands`。

### 从内置命令改起

最省事的办法：在命令面板里，鼠标停在一条内置命令上，点右边的「复制来改」。

<a class="shot" href="../images/ai-mine.webp" target="_blank"><img src="../images/ai-mine.webp" alt="复制来改，和自己的命令" loading="lazy" decoding="async"></a>

1. 「复制来改」：把这条内置命令复制到命令文件夹，用记事本或 Marlin 打开改就行
2. 命令文件夹里「周报」子文件夹中的命令，自成一组

改完保存，下次打开命令面板就生效，不用重启 Marlin。和内置命令同名的，用你的版本。

### 命令文件怎么写

开头 `---` 之间是设置，下面是给 AI 的要求：

```markdown
---
description: 整理成「进展 / 风险 / 下周计划」三段
scope: document
action: replace
---
把下面的周报整理成「进展」「风险」「下周计划」三段，每段用列表，不编造内容。

{{content}}
```

设置项（都可以不写，按默认来）：

| 设置 | 可以写 | 默认 | 说明 |
|---|---|---|---|
| `description` | 一句话 | 空 | 面板里命令名后面的说明 |
| `scope` | `selection` 选区、`block` 当前段、`document` 全文、`cursor` 光标处、`diagram` 光标所在的图 | `selection` | 处理哪部分。选区类的命令没选中文字时用当前段 |
| `action` | `replace` 替换、`insert` 插在后面、`show` 只显示 | `replace` | 结果怎么用。`show` 只在一个框里显示结果，不改文档 |
| `context` | <kbd>0</kbd>、<kbd>1</kbd>、<kbd>2</kbd> | <kbd>0</kbd> | 带上前后几段给 AI 作参考，参考的段落不会被改 |
| `fullContext` | `true`、`false` | `false` | 是否带上全文作背景，太长时只带目录和相关的几节 |
| `input` | 一句提示 | 空 | 执行前先让你填一句话，这里是输入框里的提示，比如「什么语气」 |
| `model` | 模型的名称 | 默认模型 | 这条命令固定用哪个模型（设置里添加时起的名字） |
| `output` | `text`、`mermaid`、`titles` | `text` | 结果是什么：普通文字；一张 Mermaid 图（会先检查能不能画出来）；一组标题（每行一个，像「标题备选」那样点选） |

要求里可以用这些占位，执行时换成对应的内容：

| 占位 | 换成 |
|---|---|
| `{{content}}` | 要处理的文字（按 `scope`）。没写的话，自动接在要求的最后 |
| `{{context}}` | 前后的参考段落（按 `context`） |
| `{{document}}` | 全文背景 |
| `{{input}}` | 你在输入框里填的那句话 |
| `{{language}}` | 文档主要用的语言，自动判断 |
| `{{error}}` | 图当前的报错（`scope: diagram` 时） |

所有命令都带着同一段说明：AI 只返回结果本身，不加解释，保持原文的语言和 Markdown 格式。所以要求里不用再写「不要解释」。
