# 快捷键

Marlin 的全部快捷键，和「设置 → 快捷键」页是同一份清单。在 Marlin 里按 <kbd>Ctrl+,</kbd> 打开设置，那一页顶上可以按功能或按键搜索。

## 常用

| 按键 | 作用 |
| --- | --- |
| <kbd>Ctrl+S</kbd> | 保存；编辑时 1 秒内连按 3 次回到阅读 |
| <kbd>Ctrl+Shift+S</kbd> | 另存为 |
| <kbd>Ctrl+Z</kbd> | 撤销 |
| <kbd>Ctrl+Y</kbd> / <kbd>Ctrl+Shift+Z</kbd> | 重做 |
| <kbd>Ctrl+F</kbd> | 查找 |
| <kbd>Ctrl+H</kbd> | 替换（阅读时先进入编辑） |
| <kbd>E</kbd> / <kbd>Ctrl+E</kbd> | 进入编辑（阅读时）；编辑时 Ctrl+E 回到阅读 |
| <kbd>Esc</kbd> | 退出编辑 |
| <kbd>Ctrl+J</kbd> | AI 命令（阅读时先进入编辑） |
| <kbd>Ctrl+Shift+P</kbd> | 快速打开：按文件名查找 |
| <kbd>Ctrl+,</kbd> | 设置 |

## 编辑文字

| 按键 | 作用 |
| --- | --- |
| <kbd>/</kbd> | 插入菜单（行首或空格后） |
| <kbd>Ctrl+B</kbd> | 加粗（光标在编辑器里时；别处是开关侧栏） |
| <kbd>Ctrl+I</kbd> | 斜体 |
| <kbd>Ctrl+K</kbd> | 插入链接 |
| <kbd>Enter</kbd> | 换行；在列表、引用里接着写下一项 |
| <kbd>Tab</kbd> | 缩进；光标在自动补上的括号、引号前时跳到它后面 |
| <kbd>Shift+Tab</kbd> | 减少缩进 |
| <kbd>Ctrl+]</kbd> / <kbd>Ctrl+[</kbd> | 增加 / 减少缩进 |
| <kbd>Ctrl+Alt+&#92;</kbd> | 重新排好选中各行的缩进 |
| <kbd>Ctrl+/</kbd> | 注释 / 取消注释（<!-- -->） |
| <kbd>Shift+Alt+A</kbd> | 给选中的内容加 / 去掉块注释 |
| <kbd>Ctrl+Enter</kbd> | 在当前行下面插一个空行 |
