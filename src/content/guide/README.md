# Marlin 使用指南

Marlin（墨鳞）是 Windows 上的 Markdown 阅读与编辑器：双击 `.md` 就看到排好版的文档，需要改的时候按 <kbd>E</kbd> 就地改完存盘；也能打开整个文件夹，当一个轻量的文档工作区用。

这份指南按「要做的事」来组织。第一次用，先看 [快速上手](./01-quick-start/)，5 分钟就能用起来；之后遇到什么事，在下面的目录里找对应的章。

> <strong class="alert-title" data-kind="tip">提示</strong>
> 不熟悉 Markdown 的写法？在 Marlin 里点标题栏最右边的「☰」→「帮助」→「Markdown 语法速查」，每种写法都配了效果对照。
