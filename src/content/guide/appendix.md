# 附录

## Markdown 语法速查

Marlin 里自带一份：☰ →「帮助」→「Markdown 语法速查」（或者设置 →「关于」里），在新标签里打开，每种写法都配了效果对照。不联网也能看。

不想记语法：编辑时输入 <kbd>/</kbd> 从插入菜单里选，见 [编辑基础](../05-editing/#用插入)。

## Marlin 的数据存在哪

安装版在 `%APPDATA%\dev.marlin-md.marlin`（在资源管理器的地址栏里粘贴这一串就能打开），便携版在程序旁边的 `data\` 文件夹。里面有：

| 文件或文件夹 | 是什么 |
|---|---|
| `settings.json` | 设置，包括加进词典的单词 |
| `recent.json` | 最近打开的文件和文件夹 |
| `positions.json` | 每篇文档上次读到的位置 |
| `window.json` | 窗口的位置和大小 |
| `history\` | [文档历史](../14-history/) |
| `recovery\` | 没保存的修改，每 30 秒存一份，保存或关闭后删掉 |
| `ai-commands\` | 自己写的 [AI 命令](../20-ai-summary-commands/#自定义命令) |
| `ai-summaries\` | [文档摘要](../20-ai-summary-commands/#文档摘要) |
| `ai-recent.json` | 命令面板里最近的提问 |
| `themes\` | 自己写的 [主题](../23-themes/#自己写一套主题) |
| `Markdown 语法速查.md` | 语法速查的文档本身 |

不在这里的：

- **AI 的密钥**：Windows 凭据管理器（控制面板 →「凭据管理器」→「Windows 凭据」）
- **Git 冲突和放弃改动时的备份**：各个仓库里的 `.git\marlin-backup\`
- **粘贴的图片**：文档旁边的 `assets\`（或设置里指定的文件夹）

Marlin 不会在你的文档文件夹里放任何别的文件。

## 已知限制

| 限制 | 说明 |
|---|---|
| 只支持 Windows | Windows 10 1809 以上、Windows 11，64 位 |
| 很大的文档 | 10 MB 级别的文档编辑时每次按键慢半秒左右；约 4 MB 以上不能导出 PDF 和打印，只能导出 HTML |
| 编码 | 不是 UTF-8 的文件先只读打开，转换成 UTF-8 后才能编辑 |
| 换行符 | CRLF 和 LF 混用的文件，保存后统一成 CRLF |
| 拼写检查 | 只查英文 |
| 快捷键 | 不能自己改 |
| 实时预览 | 编辑器左边没有 Git 改动的色条，要看换到分栏或仅源码 |
| Git | 不能切换、合并分支，没有提交历史，这些请用别的 Git 工具 |
| 放映 | 没有演讲者视图（第二块屏幕看备注），笔迹不保存 |
| 文档历史 | 每篇最多 50 份、30 天；在资源管理器里改名的文档，历史留在旧名字下 |
| 代码和配置文件 | 超过 5 MB 或二进制的文件交给系统程序打开 |
