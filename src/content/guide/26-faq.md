# 常见问题

## 安装和打开

**第一次运行时 Windows 说「已保护你的电脑」**

点「更多信息」，再点「仍要运行」。见 [安装与更新](../02-install/#第一次运行时的安全提示)。

**打不开，或者窗口一片空白**

Marlin 用 Windows 自带的 WebView2 显示界面。Windows 11 和多数 Windows 10 已经有了；没有的话，到微软官网搜「WebView2 运行时」下载安装（选「常青版」），再打开 Marlin。

**双击 `.md` 还是用记事本打开**

要把 Marlin 设为默认打开方式，见 [安装与更新](../02-install/#设为默认打开方式)。卸载重装后要重新设一次。

**从资源管理器双击文件，总是开在已有的窗口里**

这是默认行为。想每次都开新窗口：设置 →「文件与窗口」→「从外部打开」改成「总是新开窗口」。

## 阅读和编辑

**<kbd>Ctrl+Shift+T</kbd> 换不了主题**

有的输入法用这个键切换繁简体，按键被输入法拿走了。用状态栏最右边的主题按钮，或者在输入法的设置里关掉这个快捷键。

**很大的文档，编辑时打字卡**

10 MB 级别的文档在编辑态每次按键会慢半秒左右，阅读不受影响。可以把文档拆成几篇，或者改的时候用「仅源码」布局（<kbd>Alt+3</kbd>）。

**中文文档显示乱码，或者打开后不能编辑**

文件不是 UTF-8 编码（比如 GBK）。Marlin 会只读打开，并在窗口顶上提示「转为 UTF-8 并保存」，点了就能编辑。

**保存后换行符变了**

保存时保留文件原来的换行符（CRLF 或 LF）和开头的 BOM。只有 CRLF 和 LF 混着用的文件，保存后会统一成 CRLF。

**拼写检查不认中文**

拼写检查只查英文单词，中文不检查。不需要的话在设置 →「编辑器」里关掉。

**粘贴的截图存到哪了**

默认存在文档旁边的 `assets` 文件夹，文档里插的是相对路径。改位置：设置 →「编辑器」→「图片存到」。见 [编辑基础](../05-editing/#插入图片)。

**改坏了，想回到以前的样子**

- 还没保存：<kbd>Ctrl+Z</kbd> 撤销，或者退出编辑时选「放弃修改」
- 已经保存了：右键标签 →「文档历史…」，选一版还原，见 [文档历史](../14-history/)
- 文件夹在 Git 里：右键文件 →「放弃改动」，回到上次提交的样子，见 [Git 同步](../13-git/#放弃改动)

**Marlin 意外关了，没保存的内容还在吗**

Marlin 每 30 秒把没保存的修改另存一份。下次打开这篇文档时会提示「发现……的未保存修改」，点「恢复」。

## 导出

**导出 PDF 或打印时提示文档太大**

超过约 4 MB 的 Markdown（几千页）导出 PDF 和打印都太慢，Marlin 只让导出 HTML。用浏览器打开 HTML，打印需要的部分。

**导出的 PDF 是黑底的**

导出用当前主题的配色。先换成浅色主题（<kbd>Ctrl+Shift+T</kbd>）再导出。

## 文件夹和 Git

**侧栏没有「同步」页，文件树上也没有 M、U 标记**

- 电脑上没装 git：到 [git-scm.com](https://git-scm.com/) 下载安装，重新打开 Marlin
- 打开的文件夹不在 Git 仓库里
- 只打开了单个文件，没有打开文件夹

**推送时报「远端拒绝登录」**

Marlin 不保存密码，登录交给 git。用 SSH 密钥，或者在 git 弹出的登录窗口里登录（Git Credential Manager）。在命令行里能 `git push` 的话，Marlin 里也能。

**同步时提示冲突**

见 [Git 同步](../13-git/#冲突)。不想处理就点「中止」，一切回到拉取之前。

## AI

**命令面板里说「还没有 AI 模型」**

先在设置 →「AI」里添加一个模型，见 [接上一个模型](../17-ai-setup/)。

**连不上、密钥无效、额度用完、超时**

各种提示的意思和处理办法见 [接上一个模型](../17-ai-setup/#连不上时)。先在设置里对这个模型点「测试」。

**添加模型时选不了「Claude Code」**

这台电脑上没找到 Claude Code。先安装，并在终端里运行 `claude` 登录一次，再回来添加。

**提示「已设为只用本地模型」**

设置 →「AI」里打开了「只用本地模型」，云端模型用不了。关掉它，或者换一个本机模型。

**接入了 MCP，助手里却看不到 Marlin**

- 接入后要重启那个助手
- 设置 →「AI」→「MCP」里的「允许外部 AI 助手连接 Marlin」要打开
- 在状态栏里点了「断开」的助手，要重新打开 Marlin，或者把那个开关关了再打开
- 便携版换了文件夹位置，要重新「接入」

## 其他

**便携版的设置和数据在哪**

在程序旁边的 `data\` 文件夹里。换电脑时把整个文件夹一起拷走即可（AI 的密钥存在 Windows 凭据管理器里，要重新填）。

**Marlin 的数据都存在哪**

见 [附录](../appendix/#marlin-的数据存在哪)。
