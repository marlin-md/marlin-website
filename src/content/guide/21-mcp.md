# 让外部 AI 助手连接 Marlin（MCP）

Claude Code、Codex、Cursor 这类 AI 助手，平时只能改磁盘上的文件。通过 MCP（一种让助手连接其他软件的通用方式）连上 Marlin 以后，它们能看到你在 Marlin 里打开的文档（包括还没保存的内容和你选中的文字），也能直接改，改动出现在 Marlin 的编辑器里，由你决定保不保存。

比如在 Claude Code 里说「把 Marlin 里打开的周报精简一下」「按我选中的那段的格式，把下面几段也改了」。

这是给已经在用这些助手的人的功能。只想在 Marlin 里用 AI，看 [用 AI 写](../18-ai-writing/) 就够了。

## 接入

**在哪里**：设置（<kbd>Ctrl+,</kbd>）→「AI」→ 最下面的「MCP」

<a class="shot" href="../images/mcp-settings.webp" target="_blank"><img src="../images/mcp-settings.webp" alt="设置 → AI → MCP" loading="lazy" decoding="async"></a>

1. 允许外部 AI 助手连接 Marlin（默认关）
2. 常用的助手：装了的点「接入」，Marlin 替你改好它的配置；已接入的可以「移除」。没在这台电脑上找到的是灰的
3. 列表里没有的助手：点「复制配置」，粘贴进它的 MCP 设置

点「接入」时开关还关着的话，会一起打开。接入后**重启那个助手**才生效。

> <strong class="alert-title" data-kind="note">注意</strong>
> 改助手的配置文件前，Marlin 会先备份一份 `.bak`，只增删 `marlin` 这一项，别的设置原样不动。
>
> 便携版：配置里写的是 Marlin 现在所在的位置，挪了文件夹要重新接入。

## 助手能做什么

| 能做 | 说明 |
|---|---|
| 列出打开的文档 | 每个窗口里开着哪些文档，哪个是当前的，有没有未保存的修改 |
| 读文档 | 读到的就是编辑器里现在的内容，没保存的也算；很长的文档分段读 |
| 读选区 | 你选中的文字，或者光标在哪 |
| 改文档 | 改选中的部分、按片段查找替换、或整篇替换 |
| 打开文件 | 只能打开已打开的文件夹里、和已打开文档所在文件夹里的文件 |
| 打开文件夹、另存为 | 会先弹出来问你，你同意了才做 |
| 保存 | 保存它改过的文档 |

Marlin 关着的时候，助手要用它会自动把 Marlin 打开。

## 助手的改动怎么到你手里

助手的改动**不直接写进磁盘**，而是写进 Marlin 的编辑器，和你自己打字一样：

- 文档变成未保存（标签上有 `*`），看过没问题再 <kbd>Ctrl+S</kbd>
- 每次写入是一步撤销，<kbd>Ctrl+Z</kbd> 就撤回
- 写入之前，Marlin 先在 [文档历史](../14-history/) 里存一份「写入之前」，标着是哪个助手改的
- 写入的地方会短暂闪一下紫色

助手改了不在前台的文档时，那个标签上出现一个紫色小点，切过去看过就消失：

## 谁连着、改了什么

有助手连着时，状态栏右边显示紫色的「✦ Claude Code」（连着几个就列几个）。点开：

<a class="shot" href="../images/mcp-status.webp" target="_blank"><img src="../images/mcp-status.webp" alt="连着的助手和最近的写入" loading="lazy" decoding="async"></a>

- 每个助手几点连上的，「断开」它
- 这个窗口里最近的写入：哪个文档、几点、谁写的；「恢复到写入之前」把那个文档换回写入之前的内容（同样是一步撤销，不写盘）

断开的助手再来连会被拒绝，直到重新打开 Marlin，或者在设置里把「允许外部 AI 助手连接 Marlin」关了再打开。

## 什么时候写入会被拒绝

为了不和你抢着改，这些时候助手的写入会被拒绝，它会收到原因、稍后再试：

- 它读完文档以后，你又改过：要它重新读一遍再改
- 你正在用输入法打字（拼音还没上屏）
- 这个文档正在显示 Marlin 自己的 AI 逐处预览
- 文档是只读的（比如没转成 UTF-8 的文件、图片）
- 文件在磁盘上被别的程序改了，你还没处理那条提示

## 安全

- 默认关闭，你打开开关或点「接入」才允许
- 只在这台电脑上连接，不开网络端口，别的电脑连不上
- 助手只能碰 Marlin 里打开的文档、和这些文档所在文件夹里的文件；打开别的文件夹、另存到别处都要你同意
- 文档内容会被助手发给它所用的模型（比如 Claude Code 发给 Anthropic），这一段由助手决定，Marlin 管不到
