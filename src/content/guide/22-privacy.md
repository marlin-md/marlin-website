# 隐私

Marlin 是一个本地软件：文档在你的电脑上打开、保存，不需要账号，不上传文档，不统计你的使用情况。会联网的只有下面几件事，每件都由你决定。

## AI

只有在你主动使用 AI 时（执行一条 AI 命令、生成摘要、让 AI 画图改图、测试模型），Marlin 才会发送内容：

- **发什么**：只发这次要处理的那部分，命令面板底部写着，比如「将发送给 DeepSeek：选区 66 字 + 前后各 1 段」。文件夹里的其他文件、图片、附件都不发
- **发给谁**：你在设置里添加、在面板里选的那个模型。云端模型发给那家服务商；本机的 Ollama、LM Studio 不出电脑；Claude Code 发给 Anthropic
- **第一次先问**：第一次把内容发给某个云端模型（包括 Claude Code）之前，Marlin 会说明要发到哪里，你点「好的，以后不再提示」才发。本机模型不问
- **不在后台发送**：没有自动补全、自动摘要这类在你打字时悄悄发送的功能。摘要过时了也只是提示，你点「重新生成」才请求
- **只用本地模型**：设置 →「AI」里打开后，云端模型和 Claude Code 都用不了，文档内容不会离开这台电脑

密钥存在 Windows 凭据管理器里，不写进设置文件。摘要、最近的提问都只存在本机 Marlin 的数据文件夹里。

服务商怎么处理收到的内容，请看各家的隐私政策。

## 外部 AI 助手（MCP）

默认关闭。打开后，连上来的助手（比如 Claude Code）能读写 Marlin 里打开的文档，它再把内容发给它所用的模型，这一段由那个助手决定。只在这台电脑上连接，不开网络端口。见 [让外部 AI 助手连接 Marlin](../21-mcp/)。

## 检查更新

Marlin 启动几秒后在后台检查有没有新版本，一天最多一次。只是下载一个写着最新版本号的小文件（从 GitHub，连不上时从 Marlin 的国内地址），不发送任何文档内容和个人信息。

不想自动检查：设置 →「关于」，关掉「自动检查更新」，需要时点「检查更新」。

## Git

文件夹在 Git 仓库里时，Marlin 会在后台获取（只是查看）远端有没有新提交，时间间隔在设置里改；提交、拉取、推送只在你点「同步」时做。用的是你电脑上的 git 和它的登录方式，Marlin 不保存密码。见 [Git 同步](../13-git/)。

## 链接和图片

文档里的网页链接，点了才用浏览器打开。文档里引用的网络图片会像网页一样从网上加载。
