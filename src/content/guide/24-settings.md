# 设置一览

**在哪里**：<kbd>Ctrl+,</kbd>，或 ☰ →「设置」。每一页最下面的「这一页的说明」打开本指南里对应的章节。改了马上生效（编辑器的几项在下次进入编辑时生效），所有窗口一起变。

设置存在 Marlin 的数据文件夹里的 `settings.json`（安装版在 `%APPDATA%\dev.marlin-md.marlin`，便携版在程序旁边的 `data\`）。

## 外观

| 项 | 默认 | 说明 |
|---|---|---|
| 主题 | 跟随系统 | 6 套内置主题加自己写的，见 [外观与主题](../23-themes/) |
| 跟随系统明暗 | 开，明亮时 Marlin Light、暗色时 Marlin Dark | Windows 切换浅色 / 深色时跟着换 |
| 代码高亮 | 跟随主题 | 也可以选 GitHub、One Dark、Solarized Light |
| 字号 | 16 px | 12–24 |
| 行高 | 1.75 | 1.2–2.4 |
| 正文宽度 | 760 px | 520–1400 |
| 正文字体 | 空（用主题的字体） | 写字体名，如 `Noto Serif SC, serif` |

## 编辑器

下次进入编辑时生效。

| 项 | 默认 | 说明 |
|---|---|---|
| 编辑时布局 | 分栏 | 文档第一次进入编辑时用分栏、实时预览还是仅源码，见 [编辑基础](../05-editing/#三种编辑布局) |
| Tab 宽度 | 2 | 2、4、8 |
| 自动换行 | 开 | 长的一行在窗口边上折下来显示 |
| 拼写检查 | 开 | 只查英文单词，右键红线看建议或加入词典 |
| 输入 / 插入模板 | 开 | 在行首或空格后输入 <kbd>/</kbd> 弹出插入菜单 |
| 图片存到 | `assets` | 粘贴、拖进来的图片存在哪个文件夹，相对文档的位置，也可以写绝对路径；留空就和文档放在一起 |

## 文件与窗口

| 项 | 默认 | 说明 |
|---|---|---|
| 从外部打开 | 在最近使用的窗口里新开标签 | 在资源管理器里双击文件时；可改成「总是新开窗口」。在 Marlin 里点链接总是开标签，按住 `Ctrl` 点才开新窗口 |
| 自动获取远端 | 每 10 分钟 | 文件夹在 Git 仓库里时，多久看一次远端有没有新提交；可选只在打开文件夹时、5 / 10 / 30 分钟。只看不合并，见 [Git 同步](../13-git/) |

文件树的「只看 Markdown」「显示被忽略的文件」在文件树右上角的「⋯」里，见 [文件夹](../12-folders/#树上显示哪些文件)。

## 快捷键

全部快捷键，按场景分组，顶上可以按功能或按键搜索（比如「撤销」「Ctrl+Shift」）。和本指南的 [快捷键](../shortcuts/) 是同一份清单。快捷键不能自己改。
