## 2.0.2 — 2026-10-15

Marlin 会自己检查更新了：有新版本时状态栏提示，点一下就下载安装，装好后自动打开原来的窗口。安装包和历史版本搬到了公开的 [marlin-releases](https://github.com/marlin-md/marlin-releases/releases)。

这一版本身还需要手动安装一次，之后的版本就能自动更新。

### 自动更新

- 启动几秒后在后台检查，一天最多一次；只向 GitHub 查询有没有新版本，不发送任何文档内容
- 有新版本时状态栏右边出现「新版本 x.y.z」，点开能看到这一版的更新说明，可以「下载并安装」「跳过这个版本」或「以后再说」，不强制
- 安装包下载后先验签名，对不上就不装；有没保存的文档时先全部保存再装
- 设置 → 关于：「自动检查更新」开关（默认开）和「检查更新」按钮
- 便携版只提示有新版本，按钮打开下载页，不自动替换文件

### 修正

- 实时预览里点表格的格子进入编辑，页面会跳到表格下面的内容
- 分组之间有连线的流程图（如 `libs --> SINK`，`libs` 是分组）在画板里只能看、不能改
- 放映时右键菜单里有「编辑」「在画板里编辑」「编辑源码」；放映时按 `Esc` 关右键菜单会连放映一起退出

## 2.0.1 — 2026-10-11

右键菜单理顺了：各处都是同一种菜单，右键一个东西就是它的「⋯」；浏览器自带的「返回、刷新、另存为、打印」菜单不再出现。同步面板和文件树可以「放弃改动」。

### 右键菜单

- 各处的菜单样子一样：分组之间有分隔线，右边写快捷键，用不了的项置灰，删除这类操作是红色；`↑` `↓` `Enter` 可以用键盘选，`Esc` 关

- 同步面板的文件：打开、和上次提交比较、复制路径、在文件树中显示

- 文件树的文件右键最上面加了「打开」
- 输入框、文本框保留系统的剪切、复制、粘贴菜单

### 放弃改动

- 放弃前把现在的内容备份到仓库的 `.git/marlin-backup`；开着的文档有没保存的修改，也先存进备份

## 1.5.0 — 2026-10-05

按 `F5` 把文档全屏放映出来讲：先是封面，之后正文连续滚动、不分页，不用另做幻灯片。讲的时候可以用激光笔指、用画笔圈，笔迹跟着内容走，退出就清空，不改文档。

### 放映

- `F5` 或标题栏「▶ 放映」：窗口全屏，只剩文档；编辑时也能放映（放的是排好版的内容），退出后回到原来的编辑布局
- 封面：标题取文档属性里的 title、第一个一级标题或文件名，下面一行作者 · 日期；文档开头的属性表放映时不显示
- 正文自动放大到适合屏幕宽度；右下角工具条上可 `−` / `+` / 「适应」，`Ctrl 0` 回到适应屏幕
- `↓` `↑`（`PageDown` `PageUp`、空格）翻一屏；`→` `←` 在文档用到的最高两级标题之间跳；`Home` / `End` 到封面、文末；`Esc` 退出，窗口、缩放都恢复
- 鼠标停 2 秒自动隐藏
- 比一屏高的 Mermaid 图缩到一屏之内；点图全屏看全貌，可缩放、拖动，`Esc` 回到放映

### 演示笔

- 激光笔 `L`：跟着鼠标的红点，带短拖尾，不留痕迹
- 画笔 `P`：5 种颜色（`1`–`5`）、细 / 中 / 粗，线宽随数位笔压感变化
- 荧光笔 `H`：半透明黄色；橡皮 `X`：碰到哪一笔擦掉整笔；`C` 全部清除
- 笔迹跟着内容滚动和缩放，压在原来的字上；拿着笔时 `Esc` 先放下笔，再按一次才退出放映

## 1.4.0 — 2026-10-05

文件夹在 Git 仓库里时，Marlin 能看出改了什么，一键提交、拉取、推送，冲突在应用里逐个解决，也能直接克隆仓库。用的是电脑上装的 git，登录交给 git 自己（SSH 密钥或登录窗口），Marlin 不保存任何密码。不在仓库里、没装 git 时，一切和以前一样。

### 看得到改了什么

- 文件树：改过的文件标 M（黄），新文件标 U / A（绿），冲突和删除标红；里面有改动的文件夹带一个点
- 状态栏：分支，`↑` 没推送的提交数，`↓` 远端的新提交数；点它打开「同步」页签
- 打开文件夹时在后台获取一次远端，之后默认每 10 分钟一次（设置 → 打开文件 → Git），只获取不合并；不弹登录窗口
- 在终端里 commit、pull，或保存文件后，1 秒内更新
- 编辑器（分栏、仅源码）：和上次提交比，改过的行左侧有色条（新增绿、修改蓝、删除处红三角）；点色条看原来的内容，「还原这一块」

### 同步

- 侧栏「同步」页签：改动列表带勾选框，点文件名并排对比；提交说明不填就按改动生成（「更新 a.md、b.md」）
- 「同步」一键完成：保存打开的文档 → 提交勾上的 → 拉取（rebase）→ 推送；「⋯」里也能单独提交、拉取、推送、获取
- 只提交勾上的文件；还有没提交的改动时拉取，先问要不要暂存
- 出错时用中文说明原因：连不上远端、远端拒绝登录、要先拉取、没设置名字和邮箱
- 没设置提交用的名字和邮箱时在面板里填，只写进这个仓库

### 冲突

- 拉取遇到冲突时停下，逐个文件选「保留我的」「使用远端」或「手动改」；用远端的内容前先把我的版本备份到 `.git/marlin-backup`
- 编辑器里的冲突块写明上面是远端的、下面是我的，带「用远端的 / 用我的 / 两个都要」按钮
- 全部解决后「继续」完成拉取并推送；随时可以「中止」，回到拉取之前

### 克隆

- 起始页和菜单里的「克隆仓库…」：填地址、选位置（记住上次的位置），完成后打开

## 1.3.0 — 2026-10-05

编辑模式多了第三种布局「实时预览」：直接在排好版的正文里改，代码、公式、图表、表格、图片、折叠块都是原地可改的卡片，不露 Markdown。表格可以像表格软件一样编辑。

### 实时预览

- 编辑时的第三种布局，和「分栏」「仅源码」并列：`Alt+1` 分栏、`Alt+2` 实时预览、`Alt+3` 仅源码（阅读时按也直接进编辑），标题栏三段按钮点一下就到；`Ctrl+\` 照旧轮换。设置 → 编辑器里可以设为默认
- 标题、粗体、斜体、链接、列表、引用、提示框按阅读样式显示，光标所在处才露出 `**`、`#` 这些符号；任务列表的复选框点一下就勾上
- 代码块是卡片：头上选语言、复制，代码原地改，看不到围栏
- 公式块是卡片：上面写 LaTeX，下面实时排版；行内公式 `$…$` 点一下在小框里改，带预览
- Mermaid 图是卡片：上面写源码，下面边打边画；写错时一行红字指出第几行，图保留上一版；有模板、画板（流程图）和「⤢ 展开」大窗口。`/流程图` 插入后留在卡片里
- 图片点一下出工具条：改说明文字、替换、复制删除移动；拖右下角调大小（写成 `<img … width>`），「原始大小」变回去
- 折叠块 `<details>` 是卡片：头上改标题，下面直接写正文
- 脚注引用显示成上标编号，文末的定义显示成脚注区，光标碰到时露出源码
- HTML 块显示渲染结果，`⋯ → 编辑源码` 才露出源码
- 每张卡片的 `⋯`：复制整块的 Markdown、删除、上移、下移
- 复制得到 Markdown 原文；查找能找到被隐藏的内容；三种布局来回切换时停在同一行；整页缩放同样作用于实时预览
- 什么都不改时文件一个字节都不变（BOM、CRLF 保留）

### 表格

- 实时预览里点表格的某一格，表格原地变成可编辑的网格，改一格写一格；分栏和仅源码里点第一行末尾的「✎ 编辑表格」打开表格面板
- `Tab` / `Enter` 在格子间移动；增删行列、设对齐；拖行号、列头调整顺序；按某一列升序 / 降序（数字按数值、中文按拼音）
- 拖过几个格子选中一块：`Ctrl+C` 复制出去能直接贴进 Excel，`Delete` 清空，`Ctrl+V` 贴进来；格子里 `Shift+Enter` 换行
- 原表对齐就重新对齐，紧凑就保持紧凑，没改的行一个字符不动；一次 `Ctrl+Z` 退回整次编辑
- `/表格` 先在弹出的网格里选几列几行

### 文档属性

- 开头的 YAML（`---` 之间的 `title`、`owner`、`tags: [a, b]` 等）显示成一张属性表，列表是小标签；不再变成分隔线和标题，也不进大纲。阅读、分栏预览、导出都一样

### 其他

- 分栏右侧的预览和阅读模式一样只用来看，表格面板、画板都从编辑器打开，在当前布局上原地打开
- `<img src="相对路径">` 写的本地图片在预览和导出里也能显示
- 修复：脚注的引用顺序和书写顺序不同时，脚注块的行号颠倒，滚动同步跑偏

### 打开与阅读

- 注册 `.md` / `.markdown` 文件关联，双击即开；命令行 `marlin.exe <path>` 与拖拽打开
- 单实例：再次打开文件转交给已有进程，默认在最近使用的窗口里新开标签
- CommonMark + GFM：表格、任务列表、删除线、脚注、自动链接
- 代码高亮，除 syntect 自带语法外另打包 TypeScript / TSX、Kotlin、Swift、Dart、TOML、Dockerfile、Nginx、GraphQL、Protobuf、SCSS、INI
- 目录侧栏，滚动时高亮当前章节，点击跳转
- 页内查找（`Ctrl+F`），用 CSS Custom Highlight API，不改动已渲染的 DOM
- 非 UTF-8 文件（GBK、Big5、UTF-16 等）自动探测并只读打开，一键转成 UTF-8 后可编辑
- 相对路径的图片与本地 md 链接按文件所在目录解析；外链交给系统浏览器

### 编辑

- `E` 进入编辑，左源码右预览，双向滚动同步，`Ctrl+S` 保存并回到阅读态
- 保存是「写临时文件 + 原子改名」，保留原文件的 BOM 与换行符
- 保存前检测文件是否被外部改动，冲突时交给用户选择；未编辑时外部改动自动重载
- 崩溃恢复：编辑中定期快照，异常退出后重开提示恢复
- 连打时的多次改动合并成一次渲染，大文档不会越拖越远

### Mermaid

- 全图类型按需加载，纯文本文档不加载这部分代码
- 样式从主题变量推导，换主题自动重渲染
- 语法错误时保留上一次成功的图并标出行号，点击跳到源码
- 点击放大（滚轮缩放、拖拽平移）；右键复制 SVG、导出 2× PNG
- 改一张图只重渲染这一张（20 图文档实测 41 ms）
